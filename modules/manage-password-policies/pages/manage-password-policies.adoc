#  Manage Password Policies

=== Manage Password Policies

Password policies in Red Hat Directory Server 13 control user password behavior and security.

*   Configure *global password policies* that apply to all directory users.
*   Implement *fine-grained (subtree-level) password policies* for specific user groups.
*   Set up password aging, complexity requirements, and account lockout policies.
*   Administer user passwords and reset policies.
